DOM Investigation Summary

  • Application: ParaBank
  • Page: Administration (admin.htm)
  • Investigation type: DOM / Elements Inspection
  • Overall DOM observations: The page uses a traditional table-based layout for forms and structure, encapsulated within a main container (#mainPanel). It lacks modern semantic HTML tags (like <header>, <main>, <nav>, <footer>) and instead relies heavily on <div> and <table> elements with specific IDs for layout. Form controls are generally well-identified by id and name attributes, which is positive for automation.

2. DOM Structure

  • <html>: Root element.
  • <head>: Contains metadata, page title ("ParaBank | Administration"), CSS links (template.css, style.css), and a script reference to jQuery.
  • <body>: Has an onload attribute that focuses the username field.
    • div#mainPanel: The primary container for page content.
      • div#topPanel: Header branding area (logo, link to home/admin).
      • div#headerPanel: Main navigation menu (Solutions, About Us, etc.) and top-right links (home, about, contact).
      • div#bodyPanel: Layout container for columns.
        • div#leftPanel: Sidebar containing the "Customer Login" form and auxiliary links.
        • div#rightPanel: The main content area for administration settings.
      • div#footermainPanel: Contains the site footer links and copyright info.

4. Forms & Controls

  • Administration Settings Form (#adminForm):
    • Radio Buttons (Data Access Mode): accessMode (IDs: accessMode1 to accessMode4) for SOAP, REST (XML), REST (JSON), and JDBC.
    • Text Inputs: soapEndpoint, restEndpoint, endpoint, initialBalance, minimumBalance, loanProcessorThreshold.
    • Select Dropdowns: loanProvider (options: JMS, Web Service, Local) and loanProcessor (options: Available Funds, Down Payment, Combined).
  • Database Maintenance Form (name="initializeDB"):
    • Buttons: Initialize (value="INIT"), Clean (value="CLEAN").
  • JMS Service Form (name="toggleJms"):
    • Button: Startup (type="submit").
  • Login Form (Sidebar):
    • Inputs: username (text), password (password).
    • Button: Log In (type="submit").

5. DOM / Structural Findings

  • Missing <label> Elements: The Admin form uses <td> elements with bold text (e.g., <b>SOAP Endpoint:</b>) to describe inputs instead of proper <label> tags with a for attribute. This reduces accessibility.
  • Table-based Layout: The admin form and database controls are nested inside multiple tables (class="form", class="form2") for visual alignment, which complicates the DOM hierarchy.
  • Inline Styles: Frequent use of inline styles for widths (width: 50%) and background images (background: url(images/header-main.jpg)).
  • Duplicate/Empty IDs: No duplicate IDs were found in the critical form controls, which is good for stability. However, many div and a elements lack unique IDs.
  • Hidden Elements: A div#fs_div_all exists at the bottom of the body with all:initial, likely injected by a browser extension or specific tool, not part of the core app logic.

6. Automation / Locator Findings

  • Stable IDs: Excellent coverage for form fields: #soapEndpoint, #restEndpoint, #initialBalance, #loanProvider, #loanProcessor, #accessMode1 through #accessMode4.
  • Unique Names: Forms have unique names like initializeDB, toggleJms, and login.
  • Class Selectors: Navigation links can be targeted via parent classes like .leftmenu, .button, or .home.

7. Accessibility-Relevant DOM Findings

  • Missing Alt Text: The logo image in the topPanel has alt="ParaBank", but the admin-specific clear gif (images/clear.gif) has alt=null.
  • Form Accessibility: As noted, the absence of <label> tags makes the form harder for screen readers to associate text with inputs.
  • Semantic HTML: The page lacks modern semantic landmarks, making it harder for assistive technologies to navigate the page sections efficiently.

8. Evidence

  • Admin Form Snippet: <form id="adminForm" action="admin.htm" method="post">
  • Radio Button Evidence: <input id="accessMode1" name="accessMode" class="input\" type="radio" value="soap">
  • Table Structure: <tr><td align="right" width="30%"><b>SOAP Endpoint:</b></td><td width="70%"><input id="soapEndpoint" ...></td></tr>

9. Recommendations

  • Replace <table> layouts with CSS Flexbox or Grid for a cleaner DOM.
  • Implement <label> elements for all form inputs using the for attribute pointing to the input IDs.
  • Adopt Semantic HTML tags like <nav>, <header>, and <footer> to replace generic <div> containers.
