Day 14: Cymbal Direct E-Commerce Automation

## Overview
Automated end-to-end user flows for the Cymbal Direct microservices platform (\`https://cymbal-shops.retail.cymbal.dev/\`).

## Test Specs
* **select-product.spec.ts**: Navigates through catalog items.
* **add-to-cart.spec.ts**: Validates item selection and cart addition.
* **emty-cart.spec.ts**: Tests quantity updates and clearing cart items.
* **place-order.spec.ts**: Verifies the checkout and order placement flow.
