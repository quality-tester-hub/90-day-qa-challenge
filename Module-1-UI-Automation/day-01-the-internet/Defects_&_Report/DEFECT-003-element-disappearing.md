OS: macOS / Windows

Browser/App: Google Chrome / Modern Web Browser

Device: Desktop

Build/URL: Application Navigation / Contact Page Route

Navigate to the main application page or home interface.

Locate and click on the "Contact Us" navigation link or button.

The user is redirected to a "Not Found" or 404 error page, indicating that the route or endpoint is missing or incorrectly mapped.

Clicking "Contact Us" should successfully route the user to the active contact page or form without triggering a 404 error.
